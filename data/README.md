# data/

Put the organiser's files here (any names, CSV or Excel). Quyu recognises them from their columns:

- high-frequency sensor data (`timestamp, well_name, whp_psia, ..., gas_lift_rate_mscfd`)
- well tests
- choke events
- reservoir PVT
- well completion

The files in this folder are not committed to git (see `.gitignore`), because the dataset is confidential.
